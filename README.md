# RTAF Document Assistant — คู่มือติดตั้งและใช้งานบน Windows

โปรแกรมช่วยจัดทำ **บันทึกข้อความ** และส่งออกเป็นไฟล์ Microsoft Word (.docx) ที่แก้ไขต่อได้
รุ่น 0.1 (MVP) — ทำงานในเครื่องทั้งหมด ไม่ส่งข้อมูลเอกสารไปยังบริการภายนอก

> **ข้อควรทราบ** แม่แบบเริ่มต้นของโปรแกรมเป็นค่าตั้งต้นจากผู้พัฒนา **ยังไม่ได้ตรวจสอบกับระเบียบงานสารบรรณ**
> ก่อนใช้งานจริง ให้ทำสำเนาแม่แบบแล้วปรับให้ตรงกับไฟล์ต้นฉบับของหน่วย และตรวจไฟล์ Word ที่ได้ทุกครั้ง
> ระบบตรวจสอบในโปรแกรมเป็นการตรวจเบื้องต้น ไม่ใช่การรับรองความถูกต้องตามระเบียบ

## ใช้งานผ่านเว็บ (ไม่ต้องติดตั้ง)

เปิด **https://phuketradar-cloud.github.io/rtaf-document-assistant/** ด้วย Edge หรือ Chrome ได้ทั้งคอมพิวเตอร์และมือถือ

- เอกสารที่พิมพ์เก็บในเบราว์เซอร์ของเครื่องที่ใช้เท่านั้น ไม่ถูกส่งไปยัง GitHub หรือเซิร์ฟเวอร์ใด ผู้ใช้แต่ละคนไม่เห็นข้อมูลของกัน
- ข้อมูลบนเว็บนี้แยกจากข้อมูลที่ใช้ผ่าน `http://localhost:5173` — ย้ายข้อมูลด้วยเมนู ตั้งค่า → สำรองข้อมูล / นำเข้าข้อมูล
- ลิงก์นี้เปิดได้ทุกคนที่มีลิงก์ (repo เป็น Public)
- เว็บจะอัปเดตอัตโนมัติทุกครั้งที่แก้ไขโค้ดใน branch `main` (ผ่าน GitHub Actions ไฟล์ `.github/workflows/deploy.yml`)

ถ้าต้องการใช้งานแบบไม่ต่ออินเทอร์เน็ต ให้ติดตั้งในเครื่องตามขั้นตอนด้านล่าง

## 1. สิ่งที่ต้องมี

| รายการ | หมายเหตุ |
|---|---|
| Windows 10 หรือ 11 | |
| Node.js รุ่น LTS (20 ขึ้นไป) | ดาวน์โหลดจาก https://nodejs.org (เลือก "LTS") ติดตั้งแบบค่าเริ่มต้น |
| เบราว์เซอร์ Microsoft Edge หรือ Google Chrome | |
| Microsoft Word | สำหรับเปิดไฟล์ที่ส่งออก |
| ฟอนต์ที่แม่แบบใช้ เช่น TH Sarabun New | ถ้าเครื่องไม่มีฟอนต์ Word จะใช้ฟอนต์อื่นแทน ทำให้ตัดบรรทัดต่างไป |

ตรวจว่าติดตั้ง Node.js แล้ว: เปิด **PowerShell** แล้วพิมพ์

```bash
node -v
```

ถ้าแสดงเลขรุ่น เช่น `v22.x.x` แสดงว่าพร้อมใช้งาน

## 2. ติดตั้งครั้งแรก

1. คัดลอกโฟลเดอร์ `rtaf-document-assistant` ไปไว้ในเครื่อง เช่น `C:\RTAF\rtaf-document-assistant`
2. เปิด PowerShell แล้วเข้าโฟลเดอร์โปรแกรม

```bash
cd C:\RTAF\rtaf-document-assistant
```

3. ติดตั้งส่วนประกอบ (ต้องต่ออินเทอร์เน็ตเฉพาะขั้นตอนนี้)

```bash
npm install
```

> ถ้า npm แสดงคำเตือน `install-scripts ... esbuild` ไม่ต้องกังวล โปรแกรมยังทำงานได้ (ทดสอบแล้วกับ npm 11)

## 3. เปิดใช้งานโปรแกรม

**วิธีที่ง่ายที่สุด:** ดับเบิลคลิกไฟล์ `start.bat` ในโฟลเดอร์โปรแกรม
(ครั้งแรกจะติดตั้งส่วนประกอบให้อัตโนมัติ) แล้วเบราว์เซอร์จะเปิดที่ `http://localhost:5173`

**หรือใช้คำสั่งใน PowerShell:**

```bash
npm start
```

- หน้าต่างดำ (Command Prompt/PowerShell) ต้องเปิดค้างไว้ระหว่างใช้งาน ปิดหน้าต่างเมื่อเลิกใช้
- โปรแกรมเปิดให้เข้าถึงได้เฉพาะเครื่องนี้ (`localhost`) เท่านั้น
- ถ้าขึ้นข้อความ `Port 5173 is in use` แสดงว่ามีโปรแกรมเปิดอยู่แล้ว ให้ใช้หน้าต่างเดิม หรือปิดหน้าต่างเดิมก่อน

## 4. วิธีใช้งานโดยย่อ

| เมนู | ใช้ทำอะไร |
|---|---|
| Dashboard | ดูจำนวนเอกสารทั้งหมด ฉบับร่าง ส่งออกแล้ว และเอกสารที่แก้ไขล่าสุด |
| สร้างเอกสาร | กรอกแบบฟอร์มด้านซ้าย ดูตัวอย่างด้านขวา กด **บันทึกฉบับร่าง** และ **ส่งออก Word (.docx)** |
| เอกสารทั้งหมด | ค้นหาจากชื่อเรื่อง/เลขที่ และช่วงวันที่ เปิดแก้ไข ทำสำเนา ลบ (มีถามยืนยัน) |
| แม่แบบ | ทำสำเนาแม่แบบ ปรับฟอนต์ ระยะขอบ ระยะบรรทัด ตำแหน่งข้อความ ป้ายชื่อ และช่องที่จำเป็น |
| ตั้งค่า | เลือกแม่แบบเริ่มต้น สำรองข้อมูล นำเข้าข้อมูล ลบข้อมูลทั้งหมด |

เคล็ดลับการกรอกเนื้อหา
- กด Enter = ขึ้นย่อหน้าใหม่ (ย่อหน้าตามค่าในแม่แบบ)
- บรรทัดว่าง = บรรทัดว่างในเอกสาร
- ปุ่ม **แทรกตัวแบ่งหน้า** จะใส่บรรทัด `[[ขึ้นหน้าใหม่]]` ซึ่งจะขึ้นหน้าใหม่ในไฟล์ Word
- ช่องที่ไม่จำเป็น (เช่น อ้างถึง สิ่งที่ส่งมาด้วย) ถ้าเว้นว่างจะไม่ปรากฏในเอกสาร

การส่งออก Word: โปรแกรมจะสร้างไฟล์ แล้วเปิดไฟล์นั้นตรวจว่าเป็นไฟล์ .docx ที่อ่านได้และมีข้อความครบ
ก่อนส่งให้เบราว์เซอร์ดาวน์โหลด (ไฟล์จะอยู่ในโฟลเดอร์ **Downloads**) — โปรดเปิดตรวจใน Word ทุกครั้ง

## 5. การเก็บข้อมูลและการสำรองข้อมูล

- ข้อมูลเก็บใน **Local Storage ของเบราว์เซอร์** บนเครื่องนี้ ผูกกับเบราว์เซอร์และที่อยู่ `http://localhost:5173`
  - ถ้าเปลี่ยนเบราว์เซอร์ หรือล้างประวัติ/ข้อมูลเว็บไซต์ ข้อมูลจะไม่ปรากฏ
  - **อย่าใช้โหมดไม่ระบุตัวตน (InPrivate/Incognito)** เพราะข้อมูลจะหายเมื่อปิดหน้าต่าง
- Local Storage **ไม่ได้เข้ารหัส** ห้ามใช้กับข้อมูลลับ และห้ามพิมพ์รหัสผ่านลงในเอกสาร
- ควรสำรองข้อมูลสม่ำเสมอ: เมนู **ตั้งค่า → ดาวน์โหลดไฟล์สำรองข้อมูล** (ได้ไฟล์ .json)
- ย้ายเครื่อง/กู้คืน: เมนู **ตั้งค่า → นำเข้าข้อมูล** เลือกไฟล์ .json แล้วเลือก "รวมกับข้อมูลเดิม" หรือ "แทนที่ทั้งหมด"

## 6. แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `'npm' is not recognized` | ยังไม่ได้ติดตั้ง Node.js หรือยังไม่ได้ปิด-เปิด PowerShell ใหม่หลังติดตั้ง |
| PowerShell แจ้ง `running scripts is disabled` เมื่อสั่ง npm | ใช้ `start.bat` แทน หรือสั่ง `npm.cmd start` |
| เอกสารที่เคยบันทึกหายไป | ตรวจว่าเปิดด้วยเบราว์เซอร์เดิมและที่อยู่ `http://localhost:5173` — ถ้าไม่พบ ให้นำเข้าจากไฟล์สำรองข้อมูล |
| ไฟล์ Word ตัวอักษรไม่ตรงกับแม่แบบ | ติดตั้งฟอนต์ที่แม่แบบระบุในเครื่องที่เปิดไฟล์ หรือเปลี่ยนชื่อฟอนต์ในแม่แบบให้ตรงกับที่มี |
| ข้อความ "พื้นที่จัดเก็บในเบราว์เซอร์เต็ม" | สำรองข้อมูล แล้วลบเอกสารที่ไม่ใช้ |

## 7. สำหรับผู้ดูแลระบบ / ผู้พัฒนา

```bash
npm run dev
```
เปิดโหมดพัฒนา (แก้โค้ดแล้วเห็นผลทันที) ที่ `http://localhost:5173`

```bash
npm test
```
รันชุดทดสอบอัตโนมัติ (วันที่ไทย, ระบบตรวจสอบ, สำรอง/นำเข้า, Local Storage, การสร้างไฟล์ .docx) และสร้างไฟล์ตัวอย่างใน `test-output\`

```bash
powershell -ExecutionPolicy Bypass -File scripts\word-check.ps1
```
เปิดไฟล์ใน `test-output\` ด้วย Microsoft Word จริง นับจำนวนหน้า และบันทึกเป็น PDF ไว้ตรวจการจัดหน้า (ต้องรัน `npm test` ก่อน และต้องมี Word ในเครื่อง)

```bash
npm run build
```
ตรวจชนิดข้อมูล (TypeScript) และสร้างไฟล์สำหรับใช้งานในโฟลเดอร์ `dist\`

โครงสร้างระบบและหลักการออกแบบ: ดู [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
